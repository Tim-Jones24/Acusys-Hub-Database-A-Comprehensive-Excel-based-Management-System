# Acusys Hub Database: A Comprehensive Excel based Management System
This project is a structured Excel-based database designed to streamline data management.

### Overview
The **Acusys Hub Database** is an Excel-based data management solution designed for **Acusys Hub**, a tech firm. The database provides a comprehensive structure to manage core operational data, including students, employees, courses, payroll, and attendsnce. it utilizes Excel's powerful features such as calculated colums, data validation, and dynamic formulas to maintain accuracy and efficiency in data  processing.

### Features
* **Student Data Management**: Tracks student details, including personal information and calculated age.
* **Employee Data Management**:  Maintains employee details, calculates tenure, and tracksjob information.
* **Course Management**: Organizes course information, pricing, and durations.
* **Enrollment Tracking**: Records student enrollment in various courses.
* **Payroll Management**: Tracks employee payroll details and amounts.
* **Scheduling**: Provides a detailed schedule of courses taught by employees.
* **Attendance Monitoring**: Records attendance for students and employees with start/end times and status.
* **Address Management**: Manages addresses for employees and students with structured country and state data.

### Excel Features
1.  **Calculated Columns**: Automatically computes fields like 'Age', 'Tenure', etc., using Excel functions like 'IF', 'INT', 'YEARFRAC, and 'TODAY'.
2.  **Data Validation**: Ensures accurate data entry for dropdown lists and predefined options.
3.  **Dynamic Formulas**: Handles dependencies between tables for consistent data relationships.
4.  **Formatted Worksheets**: Clear and professional formatting with table styles for readability.

### Used Cases
* **Tech Firms**: Manage employees, students, and courses schedules efficiently.
* **Training Centers**: Track enrollments, attendance, and payroll seamlessly.
* **Small Businesses**: Adapt the database for operational data tracking.

### Technology Used
* Platform: Microsoft Excel
* Features: Data Validation,, Dynamic Formulas, Table Relationships.

### Conclusion
This project serves as a versatile tool for  organizations seeking simplified yet powerful data management solutions.
